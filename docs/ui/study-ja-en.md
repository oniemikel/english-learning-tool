# 日→英学習

## 目的

日本語から英単語を想起し、運用力を高める。

## URL

`/study/ja-en`

## 利用者

認証済み利用者。

## レイアウト構成

- ヘッダー: 進捗・終了。
- メインコンテンツ: 日本語提示、英語入力、正誤/評価。
- フッター: Mobileは入力欄と送信ボタンを固定。
- レスポンシブ時のレイアウト: 単一カラム。

## コンポーネント一覧

| コンポーネント | 役割 | 状態 |
| --- | --- | --- |
| PromptCard | 日本語提示 | default |
| AnswerInput | 英語入力 | editing / submitted |
| JudgeResult | 正誤表示 | hidden / shown |

## 表示項目

日本語訳、ヒント、進捗、正解例。

## 入力項目

| 項目名 | 型 | 必須 | 初期値 | バリデーション |
| --- | --- | --- | --- | --- |
| 英語回答 | Text | ○ | 空 | 1〜100文字 |

## ボタン

| ボタン | 押下時の処理 |
| --- | --- |
| 回答する | 簡易判定し評価表示 |
| スキップ | 不正解として次へ |
| 学習を終了 | 結果へ遷移 |

## ダイアログ

中断確認Dialog。

## エラー表示

送信失敗時Alert。

## ローディング表示

採点中インジケータ。

## 空データ表示

カード0件時は結果へ。

## API

| 利用API | HTTPメソッド | レスポンス |
| --- | --- | --- |
| Mock `/api/study/review` | POST | 採点結果 |

## 状態管理

Zustand: セッション。React State: 回答入力、採点結果。

## 画面遷移

```mermaid
flowchart LR
  JAEN --> JAEN
  JAEN --> Result[/study/result]
```

## レスポンシブ仕様

Mobileはキーボード表示時に進捗情報を簡略化。
